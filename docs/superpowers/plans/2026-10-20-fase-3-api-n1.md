# Fase 3 — API N1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expor os dados do sync numa API REST só de leitura: middlewares, `/ready`, `/api/v1/meta`, `/api/v1/global`, `/api/v1/countries`, `/api/v1/countries/:code` e o OpenAPI gerado dos schemas zod.

**Architecture:** `routes` (zod) → `controllers` → `services` (puros, regras RN-04/05/06) → `repositories` (Prisma só leitura, convertem `bigint`/`Date`). `createApp(deps)` recebe os serviços prontos: os testes de API injetam repositórios falsos e rodam sem banco; o `server.ts` monta os reais com `DATABASE_URL`.

**Tech Stack:** Node 24, TypeScript ~6.0.3 (strict, NodeNext, `verbatimModuleSyntax`, `erasableSyntaxOnly`, `noUncheckedIndexedAccess`), Express 5.3, zod 4.6, Prisma 7.10 + `@prisma/adapter-pg`, pino 10 + pino-http 11, helmet 8, cors 2.8, express-rate-limit 8, zod-openapi 6, yaml 2, swagger-ui-express 5, Vitest 5, Supertest 7.

**Spec:** `docs/superpowers/specs/2026-10-20-fase-3-api-n1-design.md`

## Global Constraints

- A api **nunca** chama a fonte externa. Nunca rode `npm run sync`. Testes não usam rede (o `fetch` global é bloqueado no Vitest).
- Nunca leia, imprima ou commite `.env` (nem `api/.env`). Só o `.env.example` é editado, com valores falsos.
- `dataVersion` = `id` do último `sync_run` da fonte com status `success` ou `partial`.
- Data de referência (RN-06) = última data em que, nas duas métricas, `country_count` da view = número de países distintos da fonte em `daily_stat`.
- Participação (RN-04) = `Math.round((valor / global) * 1000) / 10`; global `0`, `null` ou ausente → `null`.
- Posição (RN-05): só `kind = 'country'` com dados na data; ordem por `total` desc, empate por `name.localeCompare(outro, 'pt-BR')`; posições distintas (1, 2, 3…).
- Erro: `{ "error": { "code", "message", "details", "requestId" } }`, `details` `null` quando vazio. Códigos e status: `VALIDATION_ERROR` 400, `COUNTRY_NOT_FOUND` 404, `NOT_FOUND` 404, `RATE_LIMITED` 429, `DATA_NOT_READY` 503, `INTERNAL_ERROR` 500 (mensagem `'internal server error'`, sem stack).
- Data fora da cobertura → 400 `VALIDATION_ERROR`, mensagem `'date is outside the data coverage'`, `details = { from, to }`.
- Rate limit: 120 req / 60 s por IP, só em `/api`. `/health` e `/ready` ficam fora.
- `X-Request-Id`: reaproveita o da requisição se casar com `^[A-Za-z0-9-]{1,64}$`, senão `crypto.randomUUID()`.
- Código, arquivos, tabelas e rotas em inglês; documentação em pt-BR; arquivos `kebab-case`.
- TS sem `any`; sem parameter properties nem `enum`; `import type` para tipos; imports relativos com `.js`.
- Prettier: `singleQuote`, `printWidth: 100`. Antes de commitar: `./node_modules/.bin/prettier --write <arquivos>` (na raiz).
- Um commit por tarefa, Conventional Commits. Branch: `feat/api-n1` (já existe; o spec já está commitado).
- Testes de integração: `docker start mapp-db-1` (porta 5435) e `npm run test:integration -w api`. Nunca `docker compose down -v`. Pare o container no fim (`docker stop mapp-db-1`).
- Verificação de cada tarefa (na raiz): `npm run lint && npm run typecheck && npm test`. Se a saída vier resumida pelo RTK, use `rtk proxy <comando>`.

```ts
import { z } from 'zod';
import { postgresUrl } from './db-env.js';

export const logLevels = ['fatal', 'error', 'warn', 'info', 'debug', 'trace', 'silent'] as const;
export const dataProviders = ['api_ninjas', 'jhu_csv', 'apify'] as const;

export const emptyAsUndefined = (value: unknown): unknown => (value === '' ? undefined : value);

const envSchema = z.object({
  NODE_ENV: z.preprocess(
    emptyAsUndefined,
    z.enum(['development', 'test', 'production']).default('development'),
  ),
  PORT: z.preprocess(
    emptyAsUndefined,
    z
      .string()
      .regex(/^\d+$/)
      .transform(Number)
      .pipe(z.number().int().min(1).max(65535))
      .default(3333),
  ),
  LOG_LEVEL: z.preprocess(emptyAsUndefined, z.enum(logLevels).default('info')),
  DATABASE_URL: postgresUrl,
  DATA_PROVIDER: z.preprocess(emptyAsUndefined, z.enum(dataProviders).default('api_ninjas')),
  WEB_ORIGIN: z
    .string()
    .regex(/^https?:\/\/[^/\s]+$/, 'must be an http(s) origin without a path or trailing slash'),
});

export type LogLevel = (typeof logLevels)[number];
export type DataProvider = (typeof dataProviders)[number];
export type Env = z.infer<typeof envSchema>;

export function loadEnv(source: NodeJS.ProcessEnv = process.env): Env {
  const result = envSchema.safeParse(source);
  if (!result.success) {
    throw new Error(`Invalid environment variables:\n${z.prettifyError(result.error)}`);
  }
  return result.data;
}
```

```ts
    httpStatus: number,
    message: string,
    details: unknown = null,
    options?: ErrorOptions,
  ) {
```

```ts
export const ISO_DATE_PATTERN = /^\d{4}-\d{2}-\d{2}$/;

// A real calendar date in YYYY-MM-DD (2023-02-30 is rejected).
export function isIsoDate(value: string): boolean {
  if (!ISO_DATE_PATTERN.test(value)) return false;
  const date = new Date(`${value}T00:00:00Z`);
  return !Number.isNaN(date.getTime()) && toIsoDate(date) === value;
}

export function toIsoDate(date: Date): string {
  return date.toISOString().slice(0, 10);
}
```

- [ ] **Step 1: Escrever o helper de dados** — `api/tests/integration/read-fixtures.ts`

Dados fictícios: `2023-03-08` tem BRA, ARG e XDP nas duas métricas; `2023-03-09` não tem ARG (a data de referência recua para `2023-03-08`); ESH nunca aparece (não conta). Três runs finalizados: `success`, `partial` e `failed`.

```ts
import type pg from 'pg';
import { resetSyncState } from './sync-state.js';

export const D1 = '2023-03-08';
export const D2 = '2023-03-09';

const STATS: ReadonlyArray<readonly [string, 'cases' | 'deaths', string, number, number]> = [
  ['BRA', 'cases', D1, 100, 10],
  ['ARG', 'cases', D1, 100, 5],
  ['XDP', 'cases', D1, 50, 0],
  ['BRA', 'deaths', D1, 10, 1],
  ['ARG', 'deaths', D1, 20, 2],
  ['XDP', 'deaths', D1, 5, 0],
  ['BRA', 'cases', D2, 110, 10],
  ['XDP', 'cases', D2, 50, 0],
  ['BRA', 'deaths', D2, 11, 1],
  ['XDP', 'deaths', D2, 5, 0],
];

export interface ReadFixture {
  sourceId: number;
  successId: number;
  partialId: number;
  failedId: number;
}

async function insertRun(
  owner: pg.Client,
  sourceId: number,
  status: string,
  day: string,
): Promise<number> {
  const result = await owner.query<{ id: number }>(
    `INSERT INTO sync_run (source_id, mode, status, started_at, finished_at)
     VALUES ($1, 'snapshot', $2, $3, $4) RETURNING id`,
    [sourceId, status, `${day}T00:00:00Z`, `${day}T00:01:00Z`],
  );
  const id = result.rows[0]?.id;
  if (id === undefined) throw new Error('sync_run insert returned no id');
  return id;
}

export async function seedReadFixture(owner: pg.Client): Promise<ReadFixture> {
  await resetSyncState(owner);
  const source = await owner.query<{ id: number }>(
    "SELECT id FROM data_source WHERE code = 'api_ninjas'",
  );
  const sourceId = source.rows[0]?.id;
  if (sourceId === undefined) throw new Error('api_ninjas source is not seeded');

  for (const [code, metric, date, total, newValue] of STATS) {
    await owner.query(
      `INSERT INTO daily_stat (country_code, metric, stat_date, source_id, total, new_value)
       VALUES ($1, $2, $3, $4, $5, $6)`,
      [code, metric, date, sourceId, total, newValue],
    );
  }
  await owner.query('REFRESH MATERIALIZED VIEW global_daily_stat');

  return {
    sourceId,
    successId: await insertRun(owner, sourceId, 'success', '2026-10-01'),
    partialId: await insertRun(owner, sourceId, 'partial', '2026-10-02'),
    failedId: await insertRun(owner, sourceId, 'failed', '2026-10-03'),
  };
}
```

```ts
import { toIsoDate } from '../lib/dates.js';
import type { Db } from '../lib/prisma.js';

export interface SourceRecord {
  id: number;
  code: string;
  name: string;
  url: string;
  license: string;
  attribution: string;
}

export interface Coverage {
  from: string | null;
  referenceDate: string | null;
  countries: number;
}

export interface DataStateRepository {
  findSource(code: string): Promise<SourceRecord | null>;
  findDataVersion(sourceId: number): Promise<number | null>;
  findCoverage(sourceId: number): Promise<Coverage>;
  hasGlobalDate(sourceId: number, date: string): Promise<boolean>;
}

interface CoverageRow {
  from: Date | null;
  referenceDate: Date | null;
  countries: number;
}

export function createDataStateRepository(db: Db): DataStateRepository {
  return {
    findSource: (code) =>
      db.dataSource.findUnique({
        where: { code },
        select: { id: true, code: true, name: true, url: true, license: true, attribution: true },
      }),

    async findDataVersion(sourceId) {
      const run = await db.syncRun.findFirst({
        where: { sourceId, status: { in: ['success', 'partial'] } },
        orderBy: { id: 'desc' },
        select: { id: true },
      });
      return run?.id ?? null;
    },

    // RN-06: last date where both metrics have every country the source has ever sent.
    async findCoverage(sourceId) {
      const [row] = await db.$queryRaw<CoverageRow[]>`
        WITH present AS (
          SELECT count(DISTINCT country_code)::int AS n FROM daily_stat WHERE source_id = ${sourceId}
        )
        SELECT
          (SELECT min(stat_date) FROM global_daily_stat WHERE source_id = ${sourceId}) AS "from",
          (SELECT max(complete.stat_date) FROM (
             SELECT stat_date FROM global_daily_stat WHERE source_id = ${sourceId}
             GROUP BY stat_date
             HAVING count(*) = 2 AND min(country_count) = (SELECT n FROM present)
           ) complete) AS "referenceDate",
          (SELECT n FROM present) AS countries`;
      return {
        from: row?.from ? toIsoDate(row.from) : null,
        referenceDate: row?.referenceDate ? toIsoDate(row.referenceDate) : null,
        countries: row?.countries ?? 0,
      };
    },

    async hasGlobalDate(sourceId, date) {
      const [row] = await db.$queryRaw<{ n: number }[]>`
        SELECT count(*)::int AS n FROM global_daily_stat
        WHERE source_id = ${sourceId} AND stat_date = ${date}::date`;
      return row?.n === 2;
    },
  };
}
```

```ts
import type { Db } from '../lib/prisma.js';

export type StatMetric = 'cases' | 'deaths';

export interface GlobalDayRow {
  metric: StatMetric;
  total: number;
  newValue: number;
  countryCount: number;
}

export interface CountryRecord {
  code: string;
  name: string;
  kind: 'country' | 'non_geographic';
  lat: number | null;
  lng: number | null;
  population: number | null;
}

export interface CountryDayValue {
  code: string;
  name: string;
  lat: number | null;
  lng: number | null;
  total: number | null;
  newValue: number | null;
}

export interface DayStat {
  code: string;
  name: string;
  metric: StatMetric;
  total: number;
  newValue: number;
}

export interface StatsRepository {
  findGlobalDay(sourceId: number, date: string): Promise<GlobalDayRow[]>;
  listCountryValues(sourceId: number, metric: StatMetric, date: string): Promise<CountryDayValue[]>;
  findCountry(code: string): Promise<CountryRecord | null>;
  listCountryDayStats(sourceId: number, date: string): Promise<DayStat[]>;
}

interface GlobalViewRow {
  metric: StatMetric;
  total: bigint;
  newValue: bigint;
  countryCount: number;
}

export function createStatsRepository(db: Db): StatsRepository {
  return {
    async findGlobalDay(sourceId, date) {
      const rows = await db.$queryRaw<GlobalViewRow[]>`
        SELECT metric::text AS metric, total, new_value AS "newValue", country_count AS "countryCount"
        FROM global_daily_stat
        WHERE source_id = ${sourceId} AND stat_date = ${date}::date
        ORDER BY metric`;
      // Global sums are bigint in the view; they stay far below 2^53.
      return rows.map((row) => ({
        metric: row.metric,
        total: Number(row.total),
        newValue: Number(row.newValue),
        countryCount: row.countryCount,
      }));
    },

    listCountryValues: (sourceId, metric, date) =>
      db.$queryRaw<CountryDayValue[]>`
        SELECT c.code, c.name, c.lat, c.lng, s.total, s.new_value AS "newValue"
        FROM country c
        LEFT JOIN daily_stat s
          ON s.country_code = c.code
         AND s.source_id = ${sourceId}
         AND s.metric = ${metric}::metric
         AND s.stat_date = ${date}::date
        WHERE c.kind = 'country'
        ORDER BY c.code`,

    async findCountry(code) {
      const country = await db.country.findUnique({ where: { code } });
      if (!country) return null;
      return {
        code: country.code,
        name: country.name,
        kind: country.kind,
        lat: country.lat,
        lng: country.lng,
        population: country.population === null ? null : Number(country.population),
      };
    },

    listCountryDayStats: (sourceId, date) =>
      db.$queryRaw<DayStat[]>`
        SELECT s.country_code AS code, c.name, s.metric::text AS metric,
               s.total, s.new_value AS "newValue"
        FROM daily_stat s
        JOIN country c ON c.code = s.country_code
        WHERE s.source_id = ${sourceId} AND s.stat_date = ${date}::date AND c.kind = 'country'
        ORDER BY s.metric, s.country_code`,
  };
}
```

```ts
export function compareNames(a: string, b: string): number {
  return a.localeCompare(b, 'pt-BR');
}

// RN-04: country ÷ global × 100, one decimal; global 0 or missing → null.
export function sharePercent(value: number, globalTotal: number | null | undefined): number | null {
  if (globalTotal === null || globalTotal === undefined || globalTotal === 0) return null;
  return Math.round((value / globalTotal) * 1000) / 10;
}

export interface RankEntry {
  code: string;
  name: string;
  total: number;
}

export interface Rank {
  rank: number | null;
  rankedCount: number;
}

// RN-05: absolute value, ties in alphabetical (pt-BR) order.
export function rankOf(code: string, entries: readonly RankEntry[]): Rank {
  const sorted = [...entries].sort((a, b) => b.total - a.total || compareNames(a.name, b.name));
  const index = sorted.findIndex((entry) => entry.code === code);
  return { rank: index === -1 ? null : index + 1, rankedCount: sorted.length };
}
```

```ts
import type { DataProvider } from '../config/env.js';
import { AppError } from '../lib/app-error.js';
import type { DataStateRepository, SourceRecord } from '../repositories/data-state.repository.js';

export interface DataState {
  sourceId: number;
  dataVersion: number;
  from: string;
  referenceDate: string;
  countries: number;
}

export interface ResolvedDate {
  state: DataState;
  date: string;
}

export interface DataStateService {
  source(): Promise<SourceRecord>;
  current(): Promise<DataState | null>;
  resolveDate(date: string | undefined): Promise<ResolvedDate>;
}

export function createDataStateService(
  repo: DataStateRepository,
  sourceCode: DataProvider,
): DataStateService {
  let sourcePromise: Promise<SourceRecord> | undefined;
  // Coverage only changes when a sync writes data, i.e. when dataVersion changes.
  let memo: DataState | undefined;

  // The source row never changes at runtime; a failed lookup is retried on the next call.
  function source(): Promise<SourceRecord> {
    if (!sourcePromise) {
      const pending = repo.findSource(sourceCode).then((found) => {
        if (!found) throw new Error(`data source ${sourceCode} is not seeded`);
        return found;
      });
      void pending.catch(() => {
        sourcePromise = undefined;
      });
      sourcePromise = pending;
    }
    return sourcePromise;
  }

  async function current(): Promise<DataState | null> {
    const { id: sourceId } = await source();
    const dataVersion = await repo.findDataVersion(sourceId);
    if (dataVersion === null) return null;
    if (memo?.dataVersion === dataVersion) return memo;

    const coverage = await repo.findCoverage(sourceId);
    if (coverage.from === null || coverage.referenceDate === null) return null;
    memo = {
      sourceId,
      dataVersion,
      from: coverage.from,
      referenceDate: coverage.referenceDate,
      countries: coverage.countries,
    };
    return memo;
  }

  async function resolveDate(date: string | undefined): Promise<ResolvedDate> {
    const state = await current();
    if (!state) throw new AppError('DATA_NOT_READY', 503, 'no data has been loaded yet');
    if (date === undefined) return { state, date: state.referenceDate };

    const outside =
      date < state.from ||
      date > state.referenceDate ||
      !(await repo.hasGlobalDate(state.sourceId, date));
    if (outside) {
      throw new AppError('VALIDATION_ERROR', 400, 'date is outside the data coverage', {
        from: state.from,
        to: state.referenceDate,
      });
    }
    return { state, date };
  }

  return { source, current, resolveDate };
}
```

```ts
import { compareNames, rankOf, sharePercent, type Rank } from './comparison.js';
import type { DataStateService } from './data-state.service.js';
import type { MetricValue } from './global.service.js';

export interface CountryListItem {
  code: string;
  name: string;
  lat: number | null;
  lng: number | null;
  total: number | null;
  new: number | null;
}

export interface CountriesListResponse {
  date: string;
  metric: StatMetric;
  countries: CountryListItem[];
}

export interface MetricComparison extends Rank {
  share: number | null;
}

export interface CountryDetailResponse {
  date: string;
  country: {
    code: string;
    name: string;
    lat: number | null;
    lng: number | null;
    population: number | null;
  };
  cases: MetricValue | null;
  deaths: MetricValue | null;
  comparison: Record<StatMetric, MetricComparison>;
}

export interface CountriesService {
  listCountries(metric: StatMetric, date: string | undefined): Promise<CountriesListResponse>;
  getCountry(code: string, date: string | undefined): Promise<CountryDetailResponse>;
}

export function createCountriesService(
  dataState: DataStateService,
  repo: StatsRepository,
): CountriesService {
  return {
    async listCountries(metric, date) {
      const resolved = await dataState.resolveDate(date);
      const rows = await repo.listCountryValues(resolved.state.sourceId, metric, resolved.date);
      const countries = rows
        .map((row) => ({
          code: row.code,
          name: row.name,
          lat: row.lat,
          lng: row.lng,
          total: row.total,
          new: row.newValue,
        }))
        .sort((a, b) => compareNames(a.name, b.name));
      return { date: resolved.date, metric, countries };
    },

    async getCountry(code, date) {
      const resolved = await dataState.resolveDate(date);
      const country = await repo.findCountry(code);
      if (!country || country.kind !== 'country') {
        throw new AppError('COUNTRY_NOT_FOUND', 404, `country ${code} not found`, { code });
      }

      const { sourceId } = resolved.state;
      const [dayStats, globalRows] = await Promise.all([
        repo.listCountryDayStats(sourceId, resolved.date),
        repo.findGlobalDay(sourceId, resolved.date),
      ]);

      const byMetric = (metric: StatMetric) => {
        const entries = dayStats.filter((stat) => stat.metric === metric);
        const own = entries.find((stat) => stat.code === code);
        const globalTotal = globalRows.find((row) => row.metric === metric)?.total;
        return {
          value: own ? { total: own.total, new: own.newValue } : null,
          comparison: {
            share: own ? sharePercent(own.total, globalTotal) : null,
            ...rankOf(code, entries),
          },
        };
      };
      const cases = byMetric('cases');
      const deaths = byMetric('deaths');

      return {
        date: resolved.date,
        country: {
          code: country.code,
          name: country.name,
          lat: country.lat,
          lng: country.lng,
          population: country.population,
        },
        cases: cases.value,
        deaths: deaths.value,
        comparison: { cases: cases.comparison, deaths: deaths.comparison },
      };
    },
  };
}
```

```ts
import { resolveRequestId } from './request-id.js';

// Gives every request an id (req.id), echoes it in X-Request-Id and logs the response.
export function createHttpLogger(logger: Logger): RequestHandler {
  return pinoHttp({
    logger,
    genReqId: (req, res) => {
      const id = resolveRequestId(req.headers['x-request-id']);
      res.setHeader('X-Request-Id', id);
      return id;
    },
    customLogLevel: (_req, res, error) => {
      if (error || res.statusCode >= 500) return 'error';
      return res.statusCode >= 400 ? 'warn' : 'info';
    },
  });
}
```

```ts
import type { ErrorRequestHandler } from 'express';
import { ZodError } from 'zod';
import { AppError } from '../lib/app-error.js';

function clientStatusOf(error: unknown): number | undefined {
  if (typeof error !== 'object' || error === null || !('status' in error)) return undefined;
  const { status } = error;
  return typeof status === 'number' && status >= 400 && status < 500 ? status : undefined;
}

export function toAppError(error: unknown): AppError {
  if (error instanceof AppError) return error;
  if (error instanceof ZodError) {
    const details = error.issues.map((issue) => ({
      path: issue.path.join('.'),
      message: issue.message,
    }));
    return new AppError('VALIDATION_ERROR', 400, 'invalid request parameters', details);
  }
  if (clientStatusOf(error) !== undefined) {
    return new AppError('VALIDATION_ERROR', 400, 'invalid request');
  }
  return new AppError('INTERNAL_ERROR', 500, 'internal server error');
}

// The single final handler: same JSON shape for every error, never a stack trace.
// Express only treats a 4-parameter function as an error handler, so `_next` stays.
// eslint-disable-next-line @typescript-eslint/no-unused-vars
export const errorHandler: ErrorRequestHandler = (error: unknown, req, res, _next) => {
  const appError = toAppError(error);
  if (appError.httpStatus >= 500) {
    req.log.error({ err: error }, 'request failed');
  }
  res.status(appError.httpStatus).json({
    error: {
      code: appError.code,
      message: appError.message,
      details: appError.details,
      requestId: String(req.id),
    },
  });
};
```

```ts
export function createHealthRouter(dataState: DataStateService): Router {
  const router = express.Router();

  router.get('/health', (_req, res) => {
    res.status(200).json({ status: 'ok' });
  });

  router.get('/ready', async (_req, res) => {
    let state: DataState | null;
    try {
      state = await dataState.current();
    } catch (error) {
      throw new AppError('DATA_NOT_READY', 503, 'database is not reachable', null, {
        cause: error,
      });
    }
    if (!state) throw new AppError('DATA_NOT_READY', 503, 'no data has been loaded yet');
    res.json({ status: 'ready', dataVersion: state.dataVersion, referenceDate: state.referenceDate });
  });

  return router;
}
```

```ts
  server.on('listening', () => {
    logger.info({ port: env.PORT }, 'api listening');
  });
  server.on('error', (error) => {
    logger.fatal({ err: error }, 'api server error');
    process.exit(1);
  });

  const shutdown = (signal: NodeJS.Signals): void => {
    logger.info({ signal }, 'shutting down');
    setTimeout(() => {
      logger.error('shutdown timed out, forcing exit');
      process.exit(1);

          logger.error({ err: error }, 'failed to disconnect from the database');
        })
        .finally(() => process.exit(0));
    });
  };
  process.once('SIGTERM', shutdown);
  process.once('SIGINT', shutdown);
}
```

```ts
import { createDocument } from 'zod-openapi';
import { stringify } from 'yaml';
import type { z } from 'zod';
import {
  countriesListResponseSchema,
  countriesQuerySchema,
  countryDetailResponseSchema,
  countryParamsSchema,
  dateQuerySchema,
  errorResponseSchema,
  globalResponseSchema,
  healthResponseSchema,
  metaResponseSchema,
  readyResponseSchema,
} from '../routes/schemas.js';

export const OPENAPI_YAML_PATH = new URL('../../../docs/openapi.yaml', import.meta.url);

const json = (schema: z.ZodType, description: string) => ({
  description,
  content: { 'application/json': { schema } },
});

const commonErrors = {
  '429': json(errorResponseSchema, 'RATE_LIMITED: mais de 120 requisições por minuto'),
  '500': json(errorResponseSchema, 'INTERNAL_ERROR'),
};

const dataErrors = {
  '400': json(errorResponseSchema, 'VALIDATION_ERROR: parâmetro inválido ou data fora da cobertura'),
  ...commonErrors,
  '503': json(errorResponseSchema, 'DATA_NOT_READY: nenhum dado carregado ainda'),
};

export function createOpenApiDocument() {
  return createDocument({
    openapi: '3.1.0',
    info: {
      title: 'Mapp API',
      version: '1.0.0',
      description:
        'Dados históricos de COVID-19 por país (casos e mortes). Só leitura. Sempre exiba a data de referência e a fonte.',
    },
    paths: {
      '/health': {
        get: {
          summary: 'A API está no ar',
          responses: { '200': json(healthResponseSchema, 'API no ar') },
        },
      },
      '/ready': {
        get: {
          summary: 'A API tem dados carregados',
          responses: {
            '200': json(readyResponseSchema, 'Pronta para servir dados'),
            '503': json(errorResponseSchema, 'DATA_NOT_READY: sem dados ou banco indisponível'),
          },
        },
      },
      '/api/v1/meta': {
        get: {
          summary: 'Fonte, licença, cobertura, data de referência e último sync',
          responses: { '200': json(metaResponseSchema, 'Metadados'), ...commonErrors },
        },
      },
      '/api/v1/global': {
        get: {
          summary: 'Totais globais (soma dos países) numa data',
          requestParams: { query: dateQuerySchema },
          responses: { '200': json(globalResponseSchema, 'Totais globais'), ...dataErrors },
        },
      },
      '/api/v1/countries': {
        get: {
          summary: 'Países para o mapa, com o valor da métrica na data',
          requestParams: { query: countriesQuerySchema },
          responses: {
            '200': json(countriesListResponseSchema, 'Lista de países'),
            ...dataErrors,
          },
        },
      },
      '/api/v1/countries/{code}': {
        get: {
          summary: 'Detalhe de um país, com participação % e posição no ranking',
          requestParams: { path: countryParamsSchema, query: dateQuerySchema },
          responses: {
            '200': json(countryDetailResponseSchema, 'Detalhe do país'),
            '404': json(errorResponseSchema, 'COUNTRY_NOT_FOUND'),
            ...dataErrors,
          },
        },
      },
    },
  });
}

export function renderOpenApiYaml(): string {
  return `# Gerado por \`npm run openapi -w api\` a partir dos schemas zod. Não edite à mão.\n${stringify(createOpenApiDocument())}`;
}
```

```ts
import express, { type Router } from 'express';
import swaggerUi, { type JsonObject } from 'swagger-ui-express';

// Swagger UI assets are served from node_modules, so the docs need no CDN.
export function createDocsRouter(document: JsonObject): Router {
  const router = express.Router();
  router.get('/openapi.json', (_req, res) => {
    res.json(document);
  });
  router.use(
    '/',
    swaggerUi.serveFiles(document),
    swaggerUi.setup(document, { customSiteTitle: 'Mapp API' }),
  );
  return router;
}
```

```markdown
# ADR 0005 — Camadas da API e OpenAPI gerado

- Status: aceito
- Data: 2026-10-20

## Contexto

A F3 abriu a API REST só de leitura (`/ready`, `/api/v1/meta`, `/global`, `/countries`, `/countries/:code`). Precisávamos testar cada endpoint sem depender do banco, manter o contrato do front em sincronia com o código e servir a documentação.

## Decisão

- **Camadas:** `routes` (schemas zod) → `controllers` (traduzem HTTP) → `services` (regras puras: data de referência, participação, posição) → `repositories` (Prisma só leitura, convertem `bigint`/`Date`).
- **Injeção:** `createApp(deps)` recebe os serviços prontos. Os testes de API usam repositórios falsos em memória; o `server.ts` monta os reais com `DATABASE_URL` (usuário `mapp_api`). Um teste de integração roda o app real contra o Postgres.
- **OpenAPI:** os schemas zod (com `.meta()`) geram o documento pelo `zod-openapi`. `npm run openapi -w api` grava `docs/openapi.yaml`; um teste falha se o arquivo estiver desatualizado. Os testes de API validam as respostas com os mesmos schemas. A UI fica em `/api/docs` (`swagger-ui-express`, sem CDN) e o JSON em `/api/docs/openapi.json`.
- **Estado dos dados:** `dataVersion` = último `sync_run` com `success` ou `partial`. A data de referência (RN-06) e a cobertura vêm da view e ficam em memória por `dataVersion`.

## Consequências

- Mudar um schema exige rodar `npm run openapi -w api` e commitar o `docs/openapi.yaml`; o CI acusa o esquecimento.
- Os tipos do front (F4) saem do `docs/openapi.yaml`.
- O memo por `dataVersion` custa uma consulta barata por requisição (o id do último run) e evita recalcular a data de referência sobre toda a série.
```
