# Fase 4 — Front N1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first Mapp front: Leaflet world map (neutral clickable polygons + proportional markers), country search, routes `/`, `/paises/:code`, `/sobre`, `*`, cards Geral and Por país, and the fixed data banner, all fed only by the F3 API.

**Architecture:**
- React 19 + Vite. TanStack Query holds server state; React Router holds the selected country (`/paises/:code`) and the metric (`?metric=`).
- A typed `openapi-fetch` client sits over types generated from `docs/openapi.yaml`.
- Pure helpers (format, marker scale, polygon links, search normalization) are unit-tested. Components are tested with Testing Library + MSW, with the map stubbed in page tests. Leaflet behaviour is covered by Playwright E2E against a mocked API.

**Tech Stack:** react-router 8, @tanstack/react-query 5, leaflet 1.9 + react-leaflet 5, openapi-fetch 0.17, openapi-typescript 7 (dev), msw 3 (dev), Vitest 5 + jsdom, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-21-fase-4-front-n1-design.md`

## Global Constraints

- **Language:** code, file names and identifiers in English; UI copy and docs in pt-BR, exactly as written in this plan.
- **TypeScript:** `strict`, `noUncheckedIndexedAccess`, `verbatimModuleSyntax` (use `import type`), `erasableSyntaxOnly` (no parameter properties, no enums). No `any`.
- **Lint:** ESLint `recommendedTypeChecked` + react-hooks 7 + react-refresh.
  - Never leave a floating promise; use `void navigate(...)` and `onRetry={() => void query.refetch()}`.
  - Never pass an async function to an `onClick`.
- **Prettier:** `singleQuote`, `printWidth: 100`. Run `npx prettier --write <files>` before each commit.
- **Imports inside `web/src`:** extensionless relative paths (`moduleResolution: Bundler`). Files under `web/scripts` and `web/tests` use NodeNext: relative imports end in `.js`.
- **Isolation:** `web` never imports from `api/`. It may read `docs/openapi.yaml`.
- **Numbers and dates:** pt-BR via `Intl.NumberFormat('pt-BR')`. Dates `YYYY-MM-DD` are shown as `DD/MM/AAAA` without going through local-time `Date`. `null` is shown as `—`.
- **Fixtures:** web fixtures use invented numbers only. The repo is public and the source's terms forbid storing its data.
- **No external calls:** unit tests run under MSW with `onUnhandledRequest: 'error'`. E2E aborts every request that is not the local Vite server or the mocked `http://api.test`.
- **Never** read, print or commit `.env` files. Never run the sync against the real source.
- **Commits:** one per task, Conventional Commits, on branch `feat/front-n1`.
- **Exit criteria for every task:** `npm run lint`, `npm run typecheck` and `npm test -w web` are green.

## Rulings made while writing the plan

- **F3 OpenAPI pending items** (YAML anchors, `default` beside `$ref`, date formats, `X-Request-Id`): a probe generated the types from the current `docs/openapi.yaml`, and they come out correct. `metric` is optional, nullable fields are `| null`, and the error code is a union. Nothing changes in the api. Task 10 records this in CLAUDE.md.
- **Map center:** the spec says `[20, 0]`. The plan uses `[30, 10]` so Greenland (lat 60–83) stays fully inside the 480 px map at zoom 2, which the E2E polygon click needs.
- **Unit vs E2E fixtures:** `web/tests/e2e/fixtures.ts` duplicates the invented data of `web/src/test/fixtures.ts` on purpose. The two live in different TS projects (Bundler vs NodeNext), and a cross-import breaks `tsc -b`.
- **Map legend:** an absolutely positioned box inside the map panel instead of a Leaflet control. Same place (bottom left) and same content.
- **E2E port:** the E2E web server runs on port 5180 with its own env, never reusing a dev server on 5173 that points to the real API.

- [ ] **Step 6: Implement `env.ts`**

`web/src/config/env.ts`:

```ts
export interface WebEnv {
  apiUrl: string;
  tilesUrl: string;
  tilesAttribution: string;
}

const API_URL_PATTERN = /^https?:\/\/[^/\s]+$/;

function text(value: unknown): string {
  return typeof value === 'string' ? value.trim() : '';
}

export function parseEnv(source: Record<string, unknown>): WebEnv {
  const apiUrl = text(source.VITE_API_URL);
  const tilesUrl = text(source.VITE_TILES_URL);
  const tilesAttribution = text(source.VITE_TILES_ATTRIBUTION);

  const invalid: string[] = [];
  if (!API_URL_PATTERN.test(apiUrl)) invalid.push('VITE_API_URL');
  if (!['{z}', '{x}', '{y}'].every((part) => tilesUrl.includes(part))) {
    invalid.push('VITE_TILES_URL');
  }
  if (tilesAttribution === '') invalid.push('VITE_TILES_ATTRIBUTION');
  if (invalid.length > 0) {
    throw new Error(`Invalid web environment: ${invalid.join(', ')}`);
  }

  return { apiUrl, tilesUrl, tilesAttribution };
}

let cached: WebEnv | undefined;

export function getEnv(): WebEnv {
  cached ??= parseEnv(import.meta.env);
  return cached;
}
```

```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { render } from '@testing-library/react';
import type { ReactElement } from 'react';
import { MemoryRouter, Route, Routes, useLocation } from 'react-router';

function LocationProbe() {
  const location = useLocation();
  return <output data-testid="location">{`${location.pathname}${location.search}`}</output>;
}

interface RenderOptions {
  route?: string;
  path?: string | string[];
}

export function renderWithProviders(ui: ReactElement, { route = '/', path }: RenderOptions = {}) {
  const queryClient = new QueryClient({
    defaultOptions: { queries: { retry: false, refetchOnWindowFocus: false } },
  });
  const paths = path === undefined ? [] : Array.isArray(path) ? path : [path];
  const content =
    paths.length === 0 ? (
      ui
    ) : (
      <Routes>
        {paths.map((item) => (
          <Route key={item} path={item} element={ui} />
        ))}
      </Routes>
    );

  return {
    queryClient,
    ...render(
      <QueryClientProvider client={queryClient}>
        <MemoryRouter initialEntries={[route]}>
          {content}
          <LocationProbe />
        </MemoryRouter>
      </QueryClientProvider>,
    ),
  };
}
```

`web/src/shared/api/client.ts`:

```ts
import createClient from 'openapi-fetch';
import { getEnv } from '../../config/env';
import type { paths } from './schema';
import type { ApiErrorCode } from './types';

export type ErrorCode = ApiErrorCode | 'NETWORK_ERROR';

const KNOWN_CODES: readonly string[] = [
  'VALIDATION_ERROR',
  'COUNTRY_NOT_FOUND',
  'NOT_FOUND',
  'RATE_LIMITED',
  'DATA_NOT_READY',
  'INTERNAL_ERROR',
] satisfies readonly ApiErrorCode[];

export class ApiError extends Error {
  readonly status: number;
  readonly code: ErrorCode;
  readonly requestId: string | null;

  constructor(
    status: number,
    code: ErrorCode,
    message: string,
    requestId: string | null,
    options?: ErrorOptions,
  ) {
    super(message, options);
    this.name = 'ApiError';
    this.status = status;
    this.code = code;
    this.requestId = requestId;
  }
}

export function isApiError(error: unknown, code: ErrorCode): boolean {
  return error instanceof ApiError && error.code === code;
}

function createApiClient(baseUrl: string) {
  // Look fetch up on every call so interceptors installed after import (MSW) still apply.
  return createClient<paths>({ baseUrl, fetch: (request: Request) => globalThis.fetch(request) });
}

type ApiClient = ReturnType<typeof createApiClient>;

let client: ApiClient | undefined;

export function apiClient(): ApiClient {
  client ??= createApiClient(getEnv().apiUrl);
  return client;
}

interface FetchResult<T> {
  data?: T;
  error?: unknown;
  response: Response;
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null;
}

function toApiError(status: number, body: unknown): ApiError {
  if (isRecord(body) && isRecord(body.error)) {
    const { code, message, requestId } = body.error;
    if (typeof code === 'string' && KNOWN_CODES.includes(code) && typeof message === 'string') {
      return new ApiError(
        status,
        code as ApiErrorCode,
        message,
        typeof requestId === 'string' ? requestId : null,
      );
    }
  }
  return new ApiError(status, 'INTERNAL_ERROR', `Resposta inesperada da API (HTTP ${status})`, null);
}

export async function unwrap<T>(pending: Promise<FetchResult<T>>): Promise<T> {
  let result: FetchResult<T>;
  try {
    result = await pending;
  } catch (cause) {
    throw new ApiError(0, 'NETWORK_ERROR', 'Não foi possível conectar à API', null, { cause });
  }
  if (result.response.ok && result.data !== undefined) return result.data;
  throw toApiError(result.response.status, result.error);
}
```

If TypeScript infers `T` as `unknown` for `unwrap(apiClient().GET(...))`, keep `FetchResult` but make `unwrap` generic over the whole result: `unwrap<R extends FetchResult<unknown>>(pending: Promise<R>): Promise<NonNullable<R['data']>>`. Note it in the report.

```ts
import type { Metric } from '../api/types';

export const EMPTY = '—';

const numberFormat = new Intl.NumberFormat('pt-BR');
const percentFormat = new Intl.NumberFormat('pt-BR', {
  minimumFractionDigits: 1,
  maximumFractionDigits: 1,
});

export const METRIC_LABELS: Record<Metric, { title: string; noun: string }> = {
  cases: { title: 'Casos', noun: 'casos' },
  deaths: { title: 'Mortes', noun: 'mortes' },
};

export function formatNumber(value: number | null | undefined): string {
  return value === null || value === undefined ? EMPTY : numberFormat.format(value);
}

export function formatPercent(value: number | null | undefined): string {
  return value === null || value === undefined ? EMPTY : `${percentFormat.format(value)}%`;
}

// Splits the string instead of using Date so the day never shifts with the local time zone.
export function formatDate(isoDate: string): string {
  const match = /^(\d{4})-(\d{2})-(\d{2})$/.exec(isoDate);
  if (!match) return isoDate;
  const [, year, month, day] = match;
  return `${day}/${month}/${year}`;
}

export function formatRank(rank: number | null, count: number): string {
  return rank === null ? EMPTY : `nº ${rank} de ${count}`;
}
```

```ts
import { useCallback } from 'react';
import { useSearchParams } from 'react-router';
import type { Metric } from '../api/types';

export function parseMetric(value: string | null): Metric {
  return value === 'deaths' ? 'deaths' : 'cases';
}

export function useMetric(): [Metric, (metric: Metric) => void] {
  const [params, setParams] = useSearchParams();
  const metric = parseMetric(params.get('metric'));
  const setMetric = useCallback(
    (next: Metric) => {
      setParams((previous) => {
        const updated = new URLSearchParams(previous);
        updated.set('metric', next);
        return updated;
      });
    },
    [setParams],
  );
  return [metric, setMetric];
}
```

```ts
const COMBINING_MARKS = /[̀-ͯ]/g;

export function normalize(text: string): string {
  return text.normalize('NFD').replace(COMBINING_MARKS, '').toLowerCase().trim();
}

export function filterCountries<T extends { name: string }>(
  items: readonly T[],
  query: string,
  limit = 8,
): T[] {
  const needle = normalize(query);
  if (needle === '') return [];
  return items
    .filter((item) => normalize(item.name).includes(needle))
    .sort((a, b) => a.name.localeCompare(b.name, 'pt-BR'))
    .slice(0, limit);
}
```

```tsx
import { useId, useMemo, useState, type KeyboardEvent } from 'react';
import { filterCountries } from './normalize';

interface SearchOption {
  code: string;
  name: string;
}

interface CountrySearchProps {
  countries: readonly SearchOption[] | undefined;
  isError: boolean;
  onSelect: (code: string) => void;
}

export function CountrySearch({ countries, isError, onSelect }: CountrySearchProps) {
  const id = useId();
  const [text, setText] = useState('');
  const [open, setOpen] = useState(false);
  const [active, setActive] = useState(-1);
  const options = useMemo(
    () => (countries ? filterCountries(countries, text) : []),
    [countries, text],
  );

  const inputId = `${id}-input`;
  const listId = `${id}-list`;
  const expanded = open && text.trim() !== '';
  const placeholder = isError
    ? 'Busca indisponível'
    : countries
      ? 'Digite o nome do país'
      : 'Carregando países…';

  function select(option: SearchOption) {
    onSelect(option.code);
    setText('');
    setOpen(false);
    setActive(-1);
  }

  function onKeyDown(event: KeyboardEvent<HTMLInputElement>) {
    if (event.key === 'ArrowDown') {
      event.preventDefault();
      setOpen(true);
      setActive((index) => (options.length === 0 ? -1 : (index + 1) % options.length));
    } else if (event.key === 'ArrowUp') {
      event.preventDefault();
      setActive((index) =>
        options.length === 0 ? -1 : index <= 0 ? options.length - 1 : index - 1,
      );
    } else if (event.key === 'Enter') {
      const option = options[active] ?? options[0];
      if (option) {
        event.preventDefault();
        select(option);
      }
    } else if (event.key === 'Escape') {
      setOpen(false);
      setActive(-1);
    }
  }

  return (
    <div className="country-search">
      <label htmlFor={inputId}>Buscar país</label>
      <input
        id={inputId}
        type="text"
        role="combobox"
        aria-expanded={expanded}
        aria-controls={listId}
        aria-autocomplete="list"
        aria-activedescendant={expanded && active >= 0 ? `${id}-option-${active}` : undefined}
        autoComplete="off"
        value={text}
        disabled={!countries}
        placeholder={placeholder}
        onChange={(event) => {
          setText(event.target.value);
          setOpen(true);
          setActive(-1);
        }}
        onKeyDown={onKeyDown}
        onBlur={() => setOpen(false)}
      />
      <ul
        id={listId}
        role="listbox"
        aria-label="Países encontrados"
        className="search-listbox"
        hidden={!expanded || options.length === 0}
      >
        {options.map((option, index) => (
          <li
            key={option.code}
            id={`${id}-option-${index}`}
            role="option"
            aria-selected={index === active}
            className="search-option"
            onMouseDown={(event) => event.preventDefault()}
            onClick={() => select(option)}
          >
            {option.name}
          </li>
        ))}
      </ul>
      {expanded && options.length === 0 && (
        <p className="search-empty" role="status">
          Nenhum país encontrado
        </p>
      )}
    </div>
  );
}
```

```ts
import type { Metric } from '../../shared/api/types';

export const MIN_RADIUS = 3;
export const MAX_RADIUS = 40;

export const METRIC_COLORS: Record<Metric, string> = {
  cases: '#dc2626',
  deaths: '#7c3aed',
};

// Area grows with the value: the radius follows the square root.
export function markerRadius(value: number | null, max: number): number {
  if (value === null || value <= 0 || max <= 0) return 0;
  const ratio = Math.min(value / max, 1);
  return Math.round((MIN_RADIUS + (MAX_RADIUS - MIN_RADIUS) * Math.sqrt(ratio)) * 10) / 10;
}

export function maxTotal(items: readonly { total: number | null }[]): number {
  return items.reduce((max, item) => Math.max(max, item.total ?? 0), 0);
}

export function niceValue(value: number): number {
  if (value <= 0) return 0;
  const base = 10 ** Math.floor(Math.log10(value));
  const fraction = value / base;
  const step = fraction >= 5 ? 5 : fraction >= 2 ? 2 : 1;
  return step * base;
}

export function legendSteps(max: number): { value: number; radius: number }[] {
  const values = [max, max / 10, max / 100].map(niceValue).filter((value) => value >= 1);
  return [...new Set(values)].map((value) => ({ value, radius: markerRadius(value, max) }));
}
```

```ts
export function resolvePolygonCode(iso3: string, knownCodes: ReadonlySet<string>): string | null {
```

```tsx
import type { Feature, Geometry } from 'geojson';
import type { Layer, Path, PathOptions } from 'leaflet';
import { useCallback, useEffect, useMemo, useRef } from 'react';
import { GeoJSON } from 'react-leaflet';
import { resolvePolygonCode } from './polygon-links';
import type { CountryGeo, GeoProperties } from './use-geo';

const BASE_STYLE: PathOptions = {
  color: '#9ca3af',
  weight: 0.5,
  fillColor: '#e5e7eb',
  fillOpacity: 0.3,
};
const SELECTED_STYLE: PathOptions = { ...BASE_STYLE, color: '#1f2937', weight: 1.5 };

interface CountryPolygonsProps {
  geo: CountryGeo;
  knownCodes: ReadonlySet<string>;
  selectedCode: string | null;
  onSelect: (code: string) => void;
}

export function CountryPolygons({ geo, knownCodes, selectedCode, onSelect }: CountryPolygonsProps) {
  const onSelectRef = useRef(onSelect);
  useEffect(() => {
    onSelectRef.current = onSelect;
  }, [onSelect]);

  const style = useCallback(
    (feature?: Feature<Geometry, GeoProperties>) => {
      const code = feature ? resolvePolygonCode(feature.properties.iso3, knownCodes) : null;
      return code !== null && code === selectedCode ? SELECTED_STYLE : BASE_STYLE;
    },
    [knownCodes, selectedCode],
  );

  // onEachFeature only runs when the layer is created, so the layer is remounted (key) when
  // the known codes change.
  const onEachFeature = useCallback(
    (feature: Feature<Geometry, GeoProperties>, layer: Layer) => {
      const iso3 = feature.properties.iso3;
      const code = resolvePolygonCode(iso3, knownCodes);
      layer.on('add', () => {
        const element = (layer as Path).getElement();
        if (!element) return;
        element.classList.add('country-polygon');
        element.setAttribute('data-iso3', iso3);
        if (code !== null) {
          element.classList.add('is-clickable');
          element.setAttribute('data-code', code);
        }
      });
      if (code !== null) {
        layer.on('click', () => onSelectRef.current(code));
      }
    },
    [knownCodes],
  );

  const key = useMemo(() => [...knownCodes].sort().join(','), [knownCodes]);
  return <GeoJSON key={key} data={geo} style={style} onEachFeature={onEachFeature} />;
}
```

```tsx
import type { CircleMarker as LeafletCircleMarker } from 'leaflet';
import { useEffect, useMemo, useRef } from 'react';
import { CircleMarker, Popup, Tooltip } from 'react-leaflet';
import type { CountryListItem, Metric } from '../../shared/api/types';
import { METRIC_LABELS, formatDate, formatNumber } from '../../shared/format/format';
import { METRIC_COLORS, markerRadius, maxTotal } from './marker-scale';

type MappableCountry = CountryListItem & { lat: number; lng: number; total: number };

function isMappable(country: CountryListItem): country is MappableCountry {
  return country.lat !== null && country.lng !== null && (country.total ?? 0) > 0;
}

interface CountryMarkersProps {
  countries: readonly CountryListItem[];
  metric: Metric;
  referenceDate: string | undefined;
  selectedCode: string | null;
  onSelect: (code: string) => void;
}

export function CountryMarkers({
  countries,
  metric,
  referenceDate,
  selectedCode,
  onSelect,
}: CountryMarkersProps) {
  const max = useMemo(() => maxTotal(countries), [countries]);
  // Biggest first, so smaller markers are drawn on top and stay clickable.
  const visible = useMemo(
    () => countries.filter(isMappable).sort((a, b) => b.total - a.total),
    [countries],
  );

  return (
    <>
      {visible.map((country) => (
        <CountryMarker
          key={`${metric}-${country.code}`}
          country={country}
          metric={metric}
          radius={markerRadius(country.total, max)}
          referenceDate={referenceDate}
          selected={country.code === selectedCode}
          onSelect={onSelect}
        />
      ))}
    </>
  );
}

interface CountryMarkerProps {
  country: MappableCountry;
  metric: Metric;
  radius: number;
  referenceDate: string | undefined;
  selected: boolean;
  onSelect: (code: string) => void;
}

function CountryMarker({
  country,
  metric,
  radius,
  referenceDate,
  selected,
  onSelect,
}: CountryMarkerProps) {
  const markerRef = useRef<LeafletCircleMarker>(null);
  const onSelectRef = useRef(onSelect);
  useEffect(() => {
    onSelectRef.current = onSelect;
  }, [onSelect]);

  const code = country.code;
  const label = `${country.name}: ${formatNumber(country.total)} ${METRIC_LABELS[metric].noun}`;

  // Leaflet draws an SVG path; make it reachable and usable from the keyboard.
  useEffect(() => {
    const marker = markerRef.current;
    const element = marker?.getElement();
    if (!marker || !element) return;
    element.setAttribute('tabindex', '0');
    element.setAttribute('role', 'button');
    element.setAttribute('aria-label', label);
    const onKeyDown = (event: KeyboardEvent) => {
      if (event.key === 'Enter' || event.key === ' ') {
        event.preventDefault();
        onSelectRef.current(code);
      }
    };
    const onFocus = () => marker.openTooltip();
    const onBlur = () => marker.closeTooltip();
    element.addEventListener('keydown', onKeyDown);
    element.addEventListener('focus', onFocus);
    element.addEventListener('blur', onBlur);
    return () => {
      element.removeEventListener('keydown', onKeyDown);
      element.removeEventListener('focus', onFocus);
      element.removeEventListener('blur', onBlur);
    };
  }, [code, label]);

  useEffect(() => {
    if (selected) markerRef.current?.openPopup();
  }, [selected]);

  const eventHandlers = useMemo(() => ({ click: () => onSelectRef.current(code) }), [code]);

  return (
    <CircleMarker
      ref={markerRef}
      center={[country.lat, country.lng]}
      radius={radius}
      pathOptions={{
        color: selected ? '#111827' : '#ffffff',
        weight: selected ? 2 : 1,
        fillColor: METRIC_COLORS[metric],
        fillOpacity: selected ? 0.9 : 0.6,
      }}
      bubblingMouseEvents={false}
      eventHandlers={eventHandlers}
    >
      <Tooltip>{label}</Tooltip>
      <Popup>
        <strong>{country.name}</strong>
        <br />
        {`${METRIC_LABELS[metric].title}: ${formatNumber(country.total)}`}
        <br />
        {`Novos no dia: ${formatNumber(country.new)}`}
        {referenceDate && (
          <>
            <br />
            {`Data: ${formatDate(referenceDate)}`}
          </>
        )}
      </Popup>
    </CircleMarker>
  );
}
```

```tsx
  countries,
  selectedCode,

  countries: readonly CountryListItem[] | undefined;
```

```ts
import type { Page, Route } from '@playwright/test';
import { countryDetail, countryList, global, meta } from './fixtures.js';

const API_ORIGIN = 'http://api.test';
const CORS_HEADERS = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': '*',
  'Access-Control-Allow-Methods': 'GET, OPTIONS',
};

function json(route: Route, status: number, body: unknown) {
  return route.fulfill({
    status,
    contentType: 'application/json',
    headers: CORS_HEADERS,
    body: JSON.stringify(body),
  });
}

function notFound(route: Route, code: string) {
  return json(route, 404, {
    error: { code: 'COUNTRY_NOT_FOUND', message: 'country not found', details: { code }, requestId: 'req-e2e' },
  });
}

function handleApi(route: Route, url: URL) {
  if (route.request().method() === 'OPTIONS') {
    return route.fulfill({ status: 204, headers: CORS_HEADERS });
  }
  const path = url.pathname;
  if (path === '/api/v1/meta') return json(route, 200, meta);
  if (path === '/api/v1/global') return json(route, 200, global);
  if (path === '/api/v1/countries') {
    return json(route, 200, countryList(url.searchParams.get('metric') === 'deaths' ? 'deaths' : 'cases'));
  }
  const match = /^\/api\/v1\/countries\/([^/]+)$/.exec(path);
  if (match?.[1]) {
    const code = decodeURIComponent(match[1]).toUpperCase();
    const detail = countryDetail(code);
    return detail ? json(route, 200, detail) : notFound(route, code);
  }
  return json(route, 404, {
    error: { code: 'NOT_FOUND', message: 'route not found', details: null, requestId: 'req-e2e' },
  });
}

// Serves the API from fixtures and blocks every other external host (tiles included).
export async function mockApi(page: Page): Promise<void> {
  await page.route('**/*', (route) => {
    const url = new URL(route.request().url());
    if (url.hostname === 'localhost') return route.continue();
    if (url.origin === API_ORIGIN) return handleApi(route, url);
    return route.abort();
  });
}
```

```markdown
# ADR 0006 — Front: dados, tipos e mapa

Data: 2026-10-21 · Status: aceita

## Contexto

A F4 cria o primeiro front do Mapp. Ele precisa falar com a API da F3 com tipos confiáveis, guardar a seleção na URL e desenhar o mapa com polígonos e marcadores acessíveis, sem chamar nada externo nos testes.

## Decisão

- **Estado do servidor:** TanStack Query.
  - `staleTime` de 5 minutos, porque os dados são históricos;
  - sem retry em 4xx e 1 retry em 5xx ou erro de rede;
  - cada componente tem a sua query, com loading, vazio e erro locais.
- **Tipos:**
  - `openapi-typescript` gera `web/src/shared/api/schema.d.ts` a partir de `docs/openapi.yaml` (`npm run api:types -w web`), e um teste falha se o arquivo estiver desatualizado;
  - o cliente é o `openapi-fetch`, e `unwrap` converte o envelope de erro em `ApiError`.
  - O `openapi-typescript` 7 declara a peer `typescript ^5.x`; o `overrides` no `package.json` raiz faz ele usar o TS 6 do workspace (ADR 0001).
- **URL:** o país fica no caminho (`/paises/:code`) e a métrica em `?metric=` (padrão `cases`).
- **Mapa:**
  - polígonos do Natural Earth numa camada neutra e clicável;
  - territórios sem país na base herdam o soberano (GRL→DNK, PRI→USA, FLK→GBR, NCL→FRA, ATF→FRA, SOL→SOM, CYN→CYP), e TKM fica sem link;
  - `CircleMarker` com raio ∝ √total, entre 3 e 40 px;
  - o `path` SVG de cada marcador recebe `tabindex`, `role="button"` e `aria-label`, e abre com Enter/Espaço.
- **Testes:**
  - Vitest + Testing Library + MSW, com fixtures inventadas, porque os termos da fonte proíbem armazenar os dados;
  - nas páginas, o mapa é trocado por um stub;
  - o Leaflet é coberto por E2E do Playwright, com a API mockada por `page.route` e todo host externo bloqueado.

## Consequências

- Mudou um schema da API? Rode `npm run openapi -w api` e `npm run api:types -w web`; os dois testes de atualização apontam o esquecimento.
- O coroplético pode reaproveitar a camada de polígonos e a regra do soberano.
- O `overrides` sai quando o `openapi-typescript` aceitar o TS 6.
```
